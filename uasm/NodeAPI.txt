Node API
HBuilderX 5.31+ App平台 蒸汽模式

uni-app x 蒸汽模式，在3个App平台都使用了js引擎，包括Android的V8、iOS的jscore、鸿蒙的arkTS/jsvm。

不同的js引擎，原本的调用方式是不一样的，各自暴露了不同的 C API。但 uni-app x 对外提供了一套统一的 Node API，屏蔽了各js引擎的差异、

它有点类似react native的jsi的作用，但规范更普适（AI更熟悉）、性能更高。

Node API，原本是 Nodejs 面向c语言开发者提供的一套API。鸿蒙系统的 C API 也使用了Node规范。

uni-app x 中，把3个App平台的js引擎操作API，统一封装为 Node API，它为开发者提供了如下价值：

成为 uasm插件 的基建，让一个c库，可以同时高性能对接到所有App平台。让一个适配过 Nodejs 的C库可以直接被 uni-app x 使用。
开发者可以自主干预c和js的通信，实现更底层的功能
在原生工程中，复用v8。 Android的v8体积不小。 原生工程中集成 uni-app x 蒸汽模式的sdk时，如果原本原生工程也有独立使用js引擎的需求，集成2套V8是不合适的。 此时原生工程可以通过 Node API 来使用 uni-app x sdk 中的js引擎，并且能跨平台使用。
支持的 Node API清单
uni-app x 中支持的 Node API 并非全集。但覆盖了常见需求，比如在c层获取和写入一个js变量的值，通过napi_run_script执行一段js脚本。
